# คู่มือแก้เนื้อหา ข้อความ และ event

ทุกอย่างในหน้านี้แก้ได้ที่ไฟล์ JSON ในโฟลเดอร์ `src/data/` ไม่ต้องแตะโค้ดเลย

| ไฟล์ | เก็บอะไร |
|---|---|
| `reactions.json` | ท่าทาง + ข้อความ + น้ำหนักการสุ่ม |
| `events.json` | สถานการณ์พิเศษ เช่น แตะครบ N ครั้ง แตะรัว เข้าครั้งแรก |
| `comfort.json` | บทสนทนาปลอบใจทั้งหมด |
| `devMessages.json` | ข้อความในป้ายพิเศษของ Dev มุมขวาล่าง |
| `backgrounds.json` | ฉากและเงื่อนไขปลดล็อก |

---

## 1. ระบบตัดสินใจว่าจะออกท่าไหน

ทุกครั้งที่แตะ ระบบไล่ตามลำดับนี้ **หยุดที่เงื่อนไขแรกที่ตรง**

```
แตะ
 ├─ 1. กำลังอยู่ในโหมดปลอบใจ?  → ข้ามไปบรรทัดถัดไปของบทสนทนา
 ├─ 2. ยอดสะสมตรงหลักไมล์พอดี? → ท่าฉลอง (ยิงครั้งเดียวต่อหนึ่งหมุด)
 ├─ 3. แตะรัวเกินเกณฑ์?         → ท่ามึนหัว
 └─ 4. ไม่เข้าเงื่อนไขไหนเลย    → สุ่มถ่วงน้ำหนักตามโซนที่แตะ เลี่ยง 3 ท่าล่าสุด
```

โค้ดส่วนนี้อยู่ที่ `src/lib/engine.ts` ฟังก์ชัน `pickTapReaction`

## 2. เพิ่มหรือแก้ข้อความตอนแตะ

เปิด `src/data/reactions.json` แต่ละก้อนหน้าตาแบบนี้

```json
{
  "id": "peek_hide",
  "animation": "shake",
  "face": "blush",
  "weight": 10,
  "duration": 1000,
  "sound": "wobble",
  "zones": ["head"],
  "particles": ["👀"],
  "messages": ["แอบมองอยู่นะ", "เห็นแล้ว!", "จะแอบทำไม"]
}
```

| ช่อง | ความหมาย |
|---|---|
| `id` | ห้ามซ้ำกับตัวอื่น ใช้อ้างอิงจาก `events.json` และ `comfort.json` |
| `animation` | ต้องมี `.anim-<ชื่อ>` ใน `index.css` |
| `face` | ต้องมี `case` ใน `Character.tsx` |
| `weight` | น้ำหนักตอนแตะ ยิ่งมากยิ่งออกบ่อย **ใส่ 0 = ไม่เข้าการสุ่ม** |
| `idleWeight` | น้ำหนักตอนน้องขยับเอง (ไม่ใส่ = ไม่เข้า) |
| `duration` | ค้างท่านี้กี่มิลลิวินาทีก่อนกลับเป็นปกติ |
| `sound` | ชื่อเสียง ดูรายชื่อในหัวข้อ 5 |
| `zones` | แตะตรงไหนถึงจะออกท่านี้ ไม่ใส่ = ทุกที่ |
| `particles` | อิโมจิที่กระเด็นออกมา สูงสุด 4 ตัว |
| `messages` | ระบบสุ่มมาหนึ่งอัน ใส่ `[]` = ไม่ขึ้นกรอบคำพูด |

**อยากให้ท่าไหนออกบ่อยขึ้น** แค่เพิ่ม `weight` ไม่ต้องคำนวณเปอร์เซ็นต์
ระบบรวมน้ำหนักทั้งหมดแล้วหารเอง เช่นถ้ามีสามท่าน้ำหนัก 30 / 10 / 10 ท่าแรกจะออกราวครึ่งนึง

**โซนที่ใช้ได้** คือ `head` `ears` `belly` `tail` และ `any` (พื้นที่ว่างรอบตัว)

## 3. แก้ event หลังคลิก

เปิด `src/data/events.json` มี 6 แบบ

### แตะครบจำนวน

```json
{ "id": "m-50", "trigger": "clickCount", "at": 50, "reaction": "milestone_party", "message": "ครึ่งร้อยแล้ว!" }
```

นับจาก**ยอดสะสมทั้งหมด** ไม่ใช่ยอดของรอบนี้ และยิงครั้งเดียวตลอดกาล (จำไว้ใน localStorage)
ถ้าอยากทดสอบซ้ำ ให้กดรีเซ็ตในแผงตั้งค่า

> ถ้าตั้งหมุดใหม่แล้วมีฉากปลดล็อกที่เลขเดียวกันใน `backgrounds.json` ข้อความจะได้บอกผู้ใช้พอดี
> แต่ถ้าตั้งเลขไม่ตรงกัน ฉากจะยังปลดล็อกอยู่ดี แค่ไม่มีใครบอก

### แตะรัว

```json
{ "id": "rapid-tap", "trigger": "rapidClick", "threshold": 9, "withinMs": 3000, "reaction": "dizzy_spin" }
```

แตะครบ 9 ครั้งใน 3 วินาที ลดเหลือ 5 จะทำให้เจอง่ายขึ้นมาก

### อยู่เฉย ๆ นาน

```json
{ "id": "idle-sleep", "trigger": "idle", "afterMs": 35000, "reaction": "sleepy_doze" }
```

มีได้อันเดียว ระบบอ่านอันแรกที่เจอ

### เข้าเว็บครั้งแรก / กลับมาหลังหายไป / ตามเวลาของวัน

```json
{ "id": "first-visit",  "trigger": "firstVisit", "reaction": "greet_wave", "message": "สวัสดี!" }
{ "id": "back-3d",      "trigger": "returnAfter", "days": 3, "reaction": "miss_you" }
{ "id": "late-night",   "trigger": "timeOfDay", "fromHour": 22, "toHour": 5, "reaction": "night_yawn" }
```

สามอันนี้ทำงาน**ตอนเปิดหน้าเว็บ**ไม่ใช่ตอนแตะ ลำดับความสำคัญคือ
ครั้งแรก > หายไปนาน > ช่วงเวลา ถ้าเข้าเงื่อนไขหลายอันจะได้อันที่สำคัญกว่า

`timeOfDay` ข้ามเที่ยงคืนได้ (`fromHour: 22, toHour: 5` = สี่ทุ่มถึงตีห้า)
ถ้าตั้งหลายช่วงทับกัน ระบบจะใช้อันที่เขียนไว้ก่อนในไฟล์

## 4. แก้บทสนทนาปลอบใจ

นี่คือส่วน "วันนี้เป็นอะไรมา" ทั้งหมด อยู่ที่ `src/data/comfort.json`

### โครงสร้าง

```
กดปุ่ม "วันนี้เป็นอะไรมา"
   ↓
[ เลือกหัวข้อ ]  ← topics ทั้งหมดในไฟล์
   ↓
น้องพูด opening ทีละบรรทัด (แตะที่ตัวน้องเพื่อข้าม)
   ↓
[ เลือกตัวเลือกย่อย ]  ← choices ของหัวข้อนั้น
   ↓
น้องพูด lines ทีละบรรทัด แล้วปิดด้วย closing
   ↓
กลับสู่โหมดปกติเอง
```

### เพิ่มหัวข้อใหม่

```json
{
  "id": "angry",
  "label": "หงุดหงิด",
  "emoji": "💢",
  "opening": [
    { "reaction": "comfort_listen", "line": "มีอะไรมากวนใจเหรอ" },
    { "reaction": "comfort_lean",   "line": "โกรธได้นะ ไม่ต้องรีบใจเย็น" }
  ],
  "choices": [
    {
      "id": "vent",
      "label": "อยากระบายออกมา",
      "reaction": "comfort_listen",
      "lines": [
        "เล่ามาเลย เราฟังอยู่",
        "ไม่ต้องเรียบเรียงให้สวยก็ได้"
      ],
      "closing": "รู้สึกเบาขึ้นบ้างมั้ย"
    }
  ]
}
```

| ช่อง | หมายเหตุ |
|---|---|
| `label` | ข้อความบนปุ่ม ควรสั้น 1–3 คำ ไม่งั้นปุ่มจะขึ้นบรรทัดใหม่ |
| `emoji` | ขึ้นหน้าปุ่ม ใส่ตัวเดียว |
| `opening` | 2–3 บรรทัดกำลังดี ยาวกว่านั้นผู้ใช้จะเริ่มเบื่อก่อนได้เลือก |
| `choices` | 2–3 ตัวเลือก ถ้ามากกว่านี้ปุ่มจะล้นจอมือถือ |
| `reaction` | ต้องเป็น `id` ที่มีจริงใน `reactions.json` |
| `closing` | ไม่ใส่ก็ได้ จะใช้ค่าเริ่มต้น "กลับมาคุยได้ทุกเมื่อเลยนะ" |

### ท่าปลอบใจที่มีให้ใช้

| id | ลักษณะ |
|---|---|
| `comfort_listen` | พยักหน้า หน้าห่วงใย ใช้ตอนรับฟัง |
| `comfort_hug` | กางแขนกอด หน้าอบอุ่น |
| `comfort_reach` | ยื่นมือมาหา หน้าเศร้า ใช้กับเรื่องหนัก |
| `comfort_lean` | เอนตัวมาใกล้ ๆ |
| `comfort_cheer` | กระโดดให้กำลังใจ หน้ามุ่งมั่น |
| `comfort_sing` | ร้องเพลง มีโน้ตดนตรีลอย |
| `comfort_sway` | โยกตัวช้า ๆ ใช้ตอนอยู่เป็นเพื่อนเงียบ ๆ |
| `comfort_quiet` | อยู่นิ่ง ๆ มองขึ้นฟ้า |

### ปรับความเร็วการพูด

`src/hooks/useComfortFlow.ts` บรรทัดบน ๆ

```ts
const MIN_HOLD_MS = 2400;  // แต่ละบรรทัดค้างอย่างน้อยเท่านี้
const MS_PER_CHAR = 75;    // บวกเพิ่มตามความยาวข้อความ
```

บรรทัดยาว 40 ตัวอักษรจะค้าง 40 × 75 = 3000ms ถ้ารู้สึกช้าไปให้ลด `MS_PER_CHAR`

### ข้อควรระวังเรื่องเนื้อหา

หัวข้อ "ไม่สบายใจ" กับ "เศร้า" มีตัวเลือกที่ชี้ไปหาความช่วยเหลือจริงอยู่ด้วย
เพราะน้องเป็นแค่ตัวการ์ตูน ไม่ใช่นักจิตวิทยา และคนที่กดเข้ามาตอนดึกอาจกำลังแย่จริง ๆ
แนะนำให้**เก็บตัวเลือกพวกนี้ไว้** และถ้าจะแก้ ให้เปลี่ยนแค่ถ้อยคำ อย่าตัดทางออกทิ้ง

เบอร์ที่ใส่ไว้คือสายด่วนสุขภาพจิต **1323** (ฟรี 24 ชม. ในไทย)
ถ้าผู้ใช้ส่วนใหญ่อยู่ประเทศอื่น ควรเปลี่ยนเป็นเบอร์ท้องถิ่นให้ตรง

## 5. เสียง

เสียงทั้งหมดสังเคราะห์สดด้วย Web Audio ไม่มีไฟล์ mp3 เลย อยู่ที่ `src/lib/audio.ts`

| id | ใช้ตอน |
|---|---|
| `pop` | แตะทั่วไป |
| `chime` | ดีใจ ต้อนรับ |
| `boing` | เด้ง จั๊กจี้ |
| `sparkle` | วิบวับ ท่าพิเศษ |
| `giggle` | หัวเราะ |
| `wobble` | งง มึน |
| `question` | สงสัย |
| `blip` | ปุ๊กสั้น ๆ สำหรับ UI |
| `soft` | คอร์ดนุ่ม ใช้ตอนปลอบใจ |
| `sad` | ไล่ลงสองโน้ตแบบอ่อนโยน |
| `hug` | คอร์ดอุ่น ค้างยาว |
| `note` | ฮัมเพลงสี่โน้ต |
| `snore` | กรน |
| `fanfare` | ฉลองหลักไมล์ |

### เพิ่มเสียงใหม่

1. เพิ่มชื่อใน `SoundId` ที่ `src/types.ts`
2. เพิ่มสูตรใน `RECIPES` ของ `audio.ts`

```ts
cheer: [
  { freq: 660, at: 0,    dur: 0.12, type: 'triangle' },
  { freq: 880, at: 0.1,  dur: 0.12, type: 'triangle' },
  { freq: 1320, at: 0.2, dur: 0.2,  type: 'triangle', gain: 0.07 },
],
```

`freq` คือความถี่ (Hz) `at` คือเริ่มเล่นที่วินาทีที่เท่าไหร่นับจากตอนสั่ง `dur` คือความยาว
`type` เลือกได้ `sine` (นุ่ม) `triangle` (สดใส) `square` (ดิจิทัล) `sawtooth` (แหลม)
`gain` คือความดัง ค่าเริ่มต้น 0.09 อย่าเกิน 0.15 ไม่งั้นจะแตก

ความถี่โน้ตที่ใช้บ่อย: โด 523 / เร 587 / มี 659 / ฟา 698 / ซอล 784 / ลา 880 / ที 988 / โดสูง 1047

## 6. ป้ายพิเศษของ Dev (มุมขวาล่าง)

หลังผู้ใช้เปิดดูครบทุกหัวข้อในโหมด "วันนี้เป็นอะไรมา" (ครบทั้ง 7 หัวข้อ) จะมีป้ายลอยเล็ก ๆ
โผล่ขึ้นมาที่มุมขวาล่างของจอ กดแล้วสุ่มข้อความให้กำลังใจจาก "Dev" ขึ้นมาเป็นบับเบิล
แค่**เปิดดู**หัวข้อก็นับแล้ว ไม่ต้องเลือกตัวเลือกย่อยให้ครบทุกอันของหัวข้อนั้น

### ไฟล์ที่เกี่ยวข้อง

| ไฟล์ | ทำอะไร |
|---|---|
| `src/data/devMessages.json` | ข้อความทั้งหมดที่จะถูกสุ่มมาโชว์ |
| `src/hooks/useDevBadge.ts` | ติดตามว่าเปิดหัวข้อไหนไปแล้วบ้าง และตัดสินว่าปลดล็อกหรือยัง |
| `src/components/DevBadge.tsx` | ตัวป้ายและบับเบิลข้อความ |

### แก้ข้อความ

เปิด `src/data/devMessages.json` เป็น array ของสตริงล้วน ๆ เพิ่ม ลบ หรือแก้ได้ตรง ๆ

```json
[
  "มีปัญหาอะไรก็ปรึกษา Dev ได้เลยนะ พร้อมเสมอ!",
  "คิดถึงเมื่อไหร่ก็ทักมาได้เลย ไม่ต้องมีเหตุผลก็ได้นะ"
]
```

ระบบจะเลี่ยงไม่ให้ข้อความเดิมออกซ้ำติดกันสองครั้ง (ถ้ามีข้อความมากกว่า 1 อัน)
ไม่มีลิมิตความยาว แต่ยาวเกิน 2 บรรทัดจะเริ่มดันบับเบิลจนดูอึดอัดบนจอมือถือเล็ก ๆ

### เปลี่ยนเงื่อนไขปลดล็อก

ตอนนี้ปลดล็อกเมื่อเปิดครบทุกหัวข้อใน `comfort.json` (7 หัวข้อ) ซึ่งคำนวณอัตโนมัติจากจำนวนหัวข้อจริง
ถ้าเพิ่มหรือลดหัวข้อในโหมดปลอบใจ เงื่อนไขนี้จะขยับตามเอง ไม่ต้องแก้อะไรเพิ่ม

อยากให้ปลดล็อกง่ายขึ้น (เช่นแค่ 3 จาก 7 หัวข้อ) แก้ที่ `useDevBadge.ts`

```ts
const total = COMFORT_TOPICS.length;      // ← เปลี่ยนจากนี้
const unlocked = visited.length >= total; // เป็นเช่น >= 3 ตรง ๆ
```

อยากให้ปลดล็อกจากเงื่อนไขอื่นแทน (เช่นแตะครบ 200 ครั้ง) ก็เขียน hook ใหม่ในสไตล์เดียวกัน
แล้วเปลี่ยน prop `unlocked` ที่ส่งเข้า `<DevBadge />` ใน `App.tsx`

### ปรับตำแหน่งและหน้าตา

ตำแหน่งป้ายกำหนดด้วย inline style ใน `DevBadge.tsx`

```tsx
style={{ bottom: 'calc(6rem + env(safe-area-inset-bottom))' }}
```

`6rem` คือระยะเผื่อให้พ้นแถบปุ่มด้านล่าง ("วันนี้เป็นอะไรมา" กับ "ตั้งค่า") ถ้าปรับเลย์เอาต์ footer
แล้วป้ายทับปุ่มพอดี ให้ปรับเลขนี้ตาม อยากขยับเข้าขอบจอมากขึ้นแก้ `right-4` เป็น `right-2`

ไอคอนบนป้าย (ตอนนี้คือ 💌) แก้ได้ตรง `<span aria-hidden="true">💌</span>` ในไฟล์เดียวกัน

### เอฟเฟกต์เรืองแสงตอนปลดล็อกครั้งแรก

ตอนปลดล็อกครั้งแรก ป้ายจะเรืองแสงวูบวาบอยู่ 4.5 วินาทีเพื่อดึงสายตา แล้วหยุดเอง
โชว์แค่ครั้งเดียวตลอดไป (จำไว้ใน localStorage) ต่อให้รีโหลดหน้าใหม่ก็ไม่โชว์ซ้ำ
เว้นแต่กดรีเซ็ตในแผงตั้งค่า ปรับระยะเวลาได้ที่ `GLOW_DURATION_MS` ใน `DevBadge.tsx`

### ทดสอบระหว่างพัฒนา

ไม่อยากไล่กดครบ 7 หัวข้อทุกครั้งที่ทดสอบ เปิด DevTools console แล้วรันคำสั่งนี้ (เปลี่ยน `mochi-tap:` ตามพรีฟิกซ์จริงถ้าแก้ไว้ใน `storage.ts`)

```js
localStorage.setItem('mochi-tap:visitedComfortTopics', JSON.stringify(
  ['lonely','uneasy','hurt','down','tired','cheer','okay']
));
location.reload();
```

## 8. ตรวจงานก่อน commit

TypeScript จะจับให้เกือบหมด ทั้งชื่อ animation ที่สะกดผิด face ที่ไม่มีจริง และ sound ที่ไม่มีสูตร

สิ่งที่ TypeScript **จับไม่ได้** และต้องดูเอง

- `reaction` ใน `events.json` / `comfort.json` ที่อ้าง `id` ที่ไม่มีอยู่ (จะตกไปใช้ท่าสำรองเงียบ ๆ)
- `.anim-xxx` ที่ลืมเขียนใน CSS (น้องจะไม่ขยับ)
- JSON ที่ลืมใส่ comma (จะพังตอนรัน)

ถ้าอยากตรวจอัตโนมัติ เขียนสคริปต์เล็ก ๆ ไว้ก็ได้ ตัวอย่างเช็กว่า `reaction` ทุกตัวมีจริง

```js
// scripts/check-data.mjs  →  รันด้วย: node scripts/check-data.mjs
import { readFileSync } from 'fs';
const R = JSON.parse(readFileSync('src/data/reactions.json'));
const E = JSON.parse(readFileSync('src/data/events.json'));
const C = JSON.parse(readFileSync('src/data/comfort.json'));
const ids = new Set(R.map(r => r.id));

const missing = [
  ...E.map(e => e.reaction),
  ...C.flatMap(t => [...t.opening.map(o => o.reaction), ...t.choices.map(c => c.reaction)]),
].filter(id => !ids.has(id));

console.log(missing.length ? `หา id ไม่เจอ: ${missing.join(', ')}` : 'ผ่านหมด');
```
