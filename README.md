# Mochi Tap

เว็บแอปหน้าเดียว มีตัวการ์ตูนอยู่กลางจอ แตะแล้วสุ่มท่าทางพร้อมข้อความ
มีโหมด "วันนี้เป็นอะไรมา" ให้เลือกอารมณ์แล้วน้องจะปลอบใจตามหัวข้อนั้น
รองรับมือถือเต็มรูปแบบ ใช้งานฟรีทั้งหมด และไม่ต้องมีฐานข้อมูลก็เล่นได้

## เริ่มใช้งาน

```bash
npm install
npm run dev      # เปิด http://localhost:5173
npm run build    # ได้ไฟล์ static ในโฟลเดอร์ dist/
npm run check    # ตรวจว่าไฟล์ข้อมูลสอดคล้องกับโค้ด
```

ต้องมี Node.js 18 ขึ้นไป (แนะนำ 20)

## มีอะไรบ้าง

- **แตะแยกโซน** หัว หู พุง หาง และพื้นที่ว่าง แต่ละโซนมีท่าเฉพาะตัว
- **ท่าสุ่ม 12 ท่า** พร้อมข้อความ กันซ้ำ 3 ท่าล่าสุด
- **ท่าที่น้องทำเอง 8 ท่า** มองซ้ายขวา กระดิกหู ยืดเส้น ฮัมเพลง โยกตัว เหม่อ — สุ่มมาเล่นทุก 6–13 วินาทีตอนไม่มีใครแตะ
- **กะพริบตาอัตโนมัติ** ทำด้วย CSS ล้วน
- **โหมดปลอบใจ** 7 หัวข้ออารมณ์ 20 ตัวเลือกย่อย บทพูด 83 บรรทัด
- **ป้ายพิเศษของ Dev** โผล่มุมขวาล่างหลังเปิดครบทุกหัวข้อปลอบใจ กดแล้วสุ่มข้อความให้กำลังใจ
- **เสียง 14 แบบ** สังเคราะห์สดด้วย Web Audio ไม่มีไฟล์ mp3 เลย
- **ฉาก 7 ฉาก** ทุ่งหญ้า ห้องนอน ชายหาด ท้องฟ้ากลางคืน คาเฟ่ ซากุระ อวกาศ — วาดด้วย SVG มีเมฆลอย ดาวกะพริบ กลีบซากุระร่วง ไอน้ำจากแก้วกาแฟ
- **ระบบปลดล็อกฉาก** ตามยอดแตะสะสม และอัปโหลดรูปพื้นหลังเองได้
- **counter สามชั้น** แตะรอบนี้ / สะสมทั้งหมด / ทุกคนรวมกัน

## ต่อ Supabase (ไม่บังคับ)

ทำเฉพาะเมื่ออยากได้ตัวเลข "ทุกคนแตะรวมกัน" ถ้าข้ามขั้นนี้ แอปยังทำงานครบทุกอย่าง

1. สร้างโปรเจกต์ที่ [supabase.com](https://supabase.com) — free tier พอ
2. SQL Editor → วางเนื้อหาทั้งหมดจาก `supabase/schema.sql` → Run
3. Project Settings → API → คัดลอก Project URL กับ anon public key
4. คัดลอก `.env.example` เป็น `.env` แล้วใส่ค่าสองตัวนั้น

anon key เป็นคีย์ที่เปิดเผยได้ตามการออกแบบของ Supabase แอปนี้เปิด RLS ให้อ่านได้อย่างเดียว
การบวกยอดต้องผ่านฟังก์ชัน `increment_taps` ที่จำกัดไม่เกิน 500 ต่อครั้ง

## ขึ้น GitHub Pages

1. push โค้ดขึ้น repo
2. Settings → Pages → Source เลือก **GitHub Actions**
3. (ถ้าใช้ Supabase) Settings → Secrets and variables → Actions → แท็บ **Variables** → เพิ่ม `VITE_SUPABASE_URL` และ `VITE_SUPABASE_ANON_KEY`
4. push เข้า `main` แล้วรอ workflow ทำงาน

`vite.config.ts` ตั้ง `base: './'` ไว้แล้ว จึงใช้ได้ทั้ง `username.github.io` และ `username.github.io/ชื่อ-repo/`

## ข้อมูลถูกเก็บที่ไหน

- ยอดสะสม ฉากที่เลือก รูปที่อัปโหลด การตั้งค่าเสียง → `localStorage` ของเครื่องผู้ใช้เท่านั้น
- ยอดรวมของทุกคน → Supabase (ถ้าตั้งค่าไว้) เก็บแค่ตัวเลขเดียว ไม่มีข้อมูลส่วนตัว
- **ตัวเลือกย่อยที่กดในโหมดปลอบใจ** (เช่นเลือก "อยากร้องไห้" หรือ "ช่วยพาหายใจหน่อย") → ไม่ถูกบันทึกที่ไหนเลย ทั้งในเครื่องและบนเซิร์ฟเวอร์
- **หัวข้ออารมณ์ที่เคยเปิดดู** (เช่น "เหงา" "เศร้า") → บันทึกไว้ใน `localStorage` เครื่องนี้เท่านั้น ใช้แค่นับว่าเปิดครบ 7 หัวข้อหรือยัง เพื่อปลดล็อกป้ายพิเศษของ Dev ไม่ส่งออกจากเครื่องและกดรีเซ็ตในแผงตั้งค่าเพื่อลบได้
- รูปที่อัปโหลดไม่เคยถูกส่งออกจากเครื่อง
